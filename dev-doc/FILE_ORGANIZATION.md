# File Organization Guide

## Directory Structure

### Root Directory
Essential project files that should remain in root:
- `README.md` - Project overview and quick start
- `PRD.md` - Product Requirements Document
- `RELEASE.md` - Release management process
- `SECURITY.md` - Security policies

### dev-doc/ Directory
Development and task-related documentation:
- Task checklists and notes
- Setup guides and prerequisites
- Internal development documentation
- Sprint and commit documentation
- Tool configuration guides

### docs/ Directory
User-facing and API documentation (to be created):
- API documentation
- User guides
- Architecture documentation

## Rules for Creating .md Files

1. **Always ask before creating new .md files**
2. **Development/task docs** → `dev-doc/`
3. **User-facing docs** → `docs/`
4. **Essential project docs** → Root (with approval)
